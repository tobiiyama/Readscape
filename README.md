## AI Assistance

I used **ChatGPT** as an AI development assistant throughout the development of **Readscape**. I used it mainly for Flutter code generation, implementation ideas, troubleshooting, debugging, UI implementation, and understanding how different parts of the application work.

I reviewed and tested the AI-generated code and made changes when it did not match my project structure, approved mockups, or intended application behavior. I also made my own decisions about the design, navigation, screen organization, and functionality of Readscape.

See **[AI-USAGE.md](AI-USAGE.md)** for the complete AI usage documentation.
